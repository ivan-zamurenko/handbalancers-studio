# Локальний перегляд

З кореня проєкту:

```sh
export PATH="$PWD/.local-tools/uv-env/bin:$PATH"
export UV_CACHE_DIR="$PWD/.local-tools/uv-cache"
uv run --locked python tools/serve_preview.py
```

Відкрити http://127.0.0.1:8000 або http://127.0.0.1:8000/plans.
Зупинка: Ctrl+C у терміналі сервера. Сервер слухає лише цей комп’ютер.
Якщо порт зайнятий уже запущеним preview, використати наявний сервер.

Працює: секції й навігація лендінгу, UK/EN, auto/light/dark, вибір тарифу,
збереження вибору в цьому браузері, діалог стану відкриття.
Без JavaScript сторінка і ціни доступні для читання.

Реєстрація/вхід, анкета, оплата, AI, кабінет і магазин ще не підключені.
Кнопки входу/продовження пояснюють це; жодних fake success або списань.
Сервер preview явно не завантажує credentials провайдерів із середовища.
