Прочитано офіційну Supabase skill `supabase-postgres-best-practices` та документацію без встановлення сторонніх інструкцій у репозиторій.

Supabase-проєкт не створено; project reference, регіон, бюджет, SMTP й потреба імпорту не визначені. З’єднання не налаштоване й не перевірене. Локальна БД, секрети та код застосунку не змінювалися.
