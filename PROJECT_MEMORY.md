# Handbalancer’s Studio — пам’ять проєкту

Оновлено: 2026-09-13. Правила: AGENTS.md. Це локальна пам’ять проєкту.

## Актуальний дозвіл

Користувач прямо доручив зараз розробити та розгорнути весь онбординг і сайт, а правки дизайну надати після. Для цього обсягу дозволено застосовувати код, конфігурацію й тести без повторного погодження кожного рядка. Публічний VPS/домен і provider credentials не надані: запускаємо локально й готуємо production deployment. Не вважати це дозволом купувати сервіси чи приймати реальні платежі.

## Погоджений продукт

- Бренд Handbalancer’s Studio; Sculpture. Оновлений явний вибір: темніший фон #090909, нейтральні графітові поверхні, чорно-білі кнопки, лише стримані кольорові акценти. Системний Apple font stack (San Francisco на Mac), одна типографічна ієрархія, вирівняні блоки, коротші відступи й тонкі роздільники. UA default + EN.
- Стек: HTML/CSS/vanilla JS, Python FastAPI REST/JSON, PostgreSQL, SQLAlchemy2, Alembic, Uvicorn, Nginx, Docker Compose, VPS, Certbot HTTPS. Jinja2 для оболонки сторінок.
- Шлях: онбординг із кількома цілями → реєстрація Google/Apple → тариф → оплата → кабінет. Telegram через бота пізніше.
- Essential €19,99: конструктор/журнал/метрики. Plus €49,99: AI-планування/відеоаналіз/звіти. Pro €179,99: також щотижневий тренерський перегляд. Pro+ €299,99: також два 30-хв дзвінки на місяць і обмежений чат. Ліміти аналізу, строки відповіді, податки й детальні умови до продажів ще уточнюються.
- Початкові два годинні дзвінки щотижня не входять у фінально погоджені пакети.
- Оновлений онбординг: кілька рівноправних напрямів без головної цілі → рівень 1 «Починаю», 2 «Щось знаю», 3 «Впевнена база» → 30/45/60/60+ хв → 1–3 дні з календарними Mon–Sun. Питання про спорядження прибрано. `minutes_plus` відрізняє 60+ від 60; часовий пояс визначається з пристрою. Плавна карусель із reduced motion; блокування вводу під час переходу запобігає пропуску натискань.
- Користувач — єдиний тренер; команди тренерів немає і не планується.
- Тарифи мають спільний нейтральний стиль. За останньою правкою Plus вибраний за замовчуванням і має приглушено-зелений рекомендаційний бейдж. Явний вибір іншого тарифу зберігається після reload. Вибір збільшує тільки вибрану картку; окрема кнопка продовження веде далі. Верхнє «Тарифи» прокручує до /#plans.
- Користувач обирає цілі, дні та час. 2–3 доступні дні означають 2–3 заняття. Кілька цілей ділять доступний час. AI враховує історію і правки тренера, звітує після заняття, планує наступний тиждень за фактичними результатами; пропуски не стають боргом.
- Автоматичне перепланування після перенесення й пізнього відео; виконані заняття незмінні. Версії звітів зберігаються.
- Контрольні вправи визначає AI/тренер, одне відео на призначену вправу. Тренер може завантажити його за клієнта. Завершення без відео дозволено, звіт позначає неперевірену техніку.
- Нотатки тренера персоналізують аналіз і є кандидатами навчання спільної моделі з контекстом. Згода на навчання, доступ/зберігання відео та перевірка нових моделей потребують окремого визначення.
- MVP AI планується на Mac M1 Pro 16ГБ; cloud GPU після перших 10 клієнтів. Це бізнес-поріг, не доведена місткість.

## Реалізація та перевірений стан

Нова програма в server/, окремо від попереднього React/Vite концепту. Реалізовано лендінг, чотири частини анкети, реєстрацію, вибір тарифу, сторінку оплати, кабінет зі збереженим профілем і чернетки privacy/terms. Google/Apple OAuth і Stripe — підготовлені серверні інтеграції. Повний AI, навчання моделей, каталог методики, вправи оцінювання і тренувальний журнал не оголошуються реалізованими цим етапом.

Без секретів провайдерів live Google/Apple/Stripe недоступні. Локальний явно позначений демонстраційний сценарій має зберігати дані у справжній PostgreSQL, бути вимкненим у production і не змішуватися з реальними підписками.

- Локально запущено http://127.0.0.1:8000/ і відкрито Chrome. API запускається через `python3 scripts/local.py serve`. Окремий PostgreSQL 14.19 працює на 127.0.0.1:55432; локальні конфігурація і дані у проігнорованих приватних файлах.
- 83 серверні тести пройшли на ізольованій studio_test; 4 попередження про deprecated API залежностей залишаються видимими. Міграція застосована, `alembic check` не знайшов розбіжностей.
- `scripts/check-site.mjs`: 18 груп сценаріїв, повний demo-шлях, кілька цілей, клавіатурний вибір, reload, UA/EN, logout; 12 axe-перевірок без порушень. Немає горизонтального переповнення на 320/390/768/1440 px для 5 маршрутів. Це автоматичні перевірки, не повний аудит WCAG.
- Скриншоти та browser-report.json: `.local-tools/verification/site/`. Інструкції запуску: `docs/local-development.md`; зовнішні інтеграції й VPS: `docs/deployment.md`.
- Docker/Compose/nginx/Certbot підготовлені; Docker відсутній на цьому Mac, контейнерний запуск, TLS і живі OAuth/Stripe не перевірялися. Stripe Checkout MVP обмежений картками. Для публічного продажу потрібні доступи, юридичні умови й реально доступні послуги.
- Deploy-перевірки: 14 passed, 1 skipped (немає Docker); Ruff успішний. Обидва Compose примусово вимикають demo: нативний loopback-сценарій і Docker bridge мають різні межі довіри. Повний запис перевірок: `docs/verification.md`.

## Відкриті питання

Користувач підтвердив наявність Stripe-акаунта. Credentials не надавались і в чаті не запитуються. Google OAuth та Sign in with Apple ще треба налаштувати окремо; домен/VPS не надані. Юридичні реквізити й VAT, каталог тестових вправ, методичні правила, limits/SLA та комерційна готовність AI залишаються відкритими. Не вигадувати кваліфікації тренера, відгуки, результати або медичні твердження.

Нові анкети зберігаються з schema_version2. Старі JSONB записи не перезаписуються: API приховує застарілі поля primary_goal/equipment, але не вигадує нові дні або тривалість. Для редагування старих несумісних варіантів потрібно зробити новий вибір. Міграція таблиць не потрібна.
