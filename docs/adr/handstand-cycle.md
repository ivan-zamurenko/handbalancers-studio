# Природний рух і стиль продукту — 2026-11-08

Останній запит власника: рухи «як в житті», плавність, оформлення в стилі
нашого сайту та застосування доречних skills. Ця вказівка замінює попереднє
перебільшене розведення ніг і великий кивок. Контурний персонаж збережений;
зміна стосується фізики руху, ритму та деталей оформлення.

Застосовано Sites skill у local-only режимі: існуючий checkout, збереження
брендингу, responsive/browser QA; без реєстрації/публікації нового сайту.
Технічний орієнтир: USA Gymnastics, прямі опорні руки, ноги разом у верхній
точці, послідовний крок на виході:
https://static.usagym.org/PDFs/Women/development/compulsory/2021/replacement_061721.pdf
Це авторська процедурна анімація за технікою, не motion capture.

Підтверджені причини неприродності попередньої версії:
- нульова швидкість таза при контакті/відриві долонь;
- різкий lock коліна через sqrt у двосегментному IK;
- стопа починала вільний мах із ненульовою швидкістю після опори.
Виправлено Hermite-траєкторіями з узгодженими похідними, анімацією кута згину
коліна та узгодженими швидкостями довжини/напрямку ноги при відштовхуванні.
Долоні під час опори нерухомі; ноги у верхній точці прямі й разом. Залишено
дуже малу поправку балансу, blink і делікатне завершення. Цикл6.6s.

Стиль: наявні tokens.css, neutral silhouette, зелений торс, менша голова,
тонка лінія/мітки опори, рухома тінь під тілом. cycle.css оформлює окрему
сторінку з радіусами8/6px як у продукті. Центральний preview224px із фігурою
148px; corner залишається компактним. No external fonts/dependencies/network.
Основний runtime loader і рішення про його розташування не змінено.

RED: два нові math-сценарії впали на старому rig: ноги не сходяться, таз
завмирає при контакті. Попередній playful-only test замінено відповідно до
останнього запиту; вихідні length/floor/continuity тести збережено.
GREEN:6 math (10,001samples + односторонні швидкості contact/release/push-off),
40 JS,5 browser (10.2s), dark/light390/1440, product tokens, pause/reduced-motion,
dialog clone/focus. Read-only reviewer без блокерів, окремо перевірив head

# Уточнення характеру й гімнастичної механіки — 2026-11-08

Власник відхилив попередній рух як надто механічний та уточнив: більше характеру
і уваги до деталей, зберегти тонкий контур і повний цикл з ніг на руки.
Референс: https://www.instagram.com/reel/DfViPqtSRxY/ (stick.dimension).
Публічна сторінка й декодовані кадри відео доступні через браузер без входу:
велика кругла контурна голова, виразність через пози. Це візуальний орієнтир,
не гімнастичний відеоурок. Поточні Instagram trends кількісно не перевірені.
Додаткове джерело техніки:
https://static.usagym.org/PDFs/Women/development/compulsory/2021/replacement_061721.pdf

Нова механіка: підтримуваний ланцюг від нерухомих зап’ясть, прямі руки,
махова нога пряма, друга відштовхується до повного розгинання коліна,
носки витягуються в повітрі. Підготовчий замах, невеликий перехід через
вертикаль і поправка балансу; повернення повільніше, руки опускаються окремо.
Голова трохи більша, з коротким з’єднанням із плечима. Рух8.2s, SVG/JS
без нових залежностей. Актуальні cycle.gif205frames/25fps та overview.gif/png.

Чому змінені математичні тести: попередні перевіряли довжини, але дозволяли
зігнуті опорні руки та механічні стопи. Нові перевіряють пряму опору,
махову ногу, носки, повний loop, 10,001samples для довжин/підлоги/неперервності.
Довжина руки46 замість50 — пропорції нового rig, не послаблення вимог.
Стояча пауза на .98 більше не обов’язкова: нове завершення досягає старту на1.
Для continuity обрано крок .0001 і max .7px: дрібніший крок відрізняє
стрибок від швидкого маху. Виявлене різке розгинання коліна усунено раннім
відштовхуванням, швидкий зворотний замах рук — окремою return track.

RED:3 tests failed на попередньому rig (немає Toe/Shoulder points, старі anchors).
Проміжний новий rig: continuity tests виявили snap коліна й надто швидкі руки.
GREEN:3 geometry,37 JS,4 browser (9.9s). Перший запуск загального JS suite
мав environment failure через відсутній PLAYWRIGHT_BROWSERS_PATH; повтор
зі шляхом до встановленого Chromium пройшов. Read-only reviewer: без блокерів,
