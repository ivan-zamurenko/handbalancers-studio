# Уточнення характеру й гімнастичної механіки — 2026-11-08

Власник відхилив попередній рух як надто механічний та уточнив: більше характеру
і уваги до деталей, зберегти тонкий контур і повний цикл з ніг на руки.
Референс: https://www.instagram.com/reel/DfViPqtSRxY/ (stick.dimension).
Публічна сторінка й декодовані кадри відео доступні через браузер без входу:
велика кругла контурна голова, виразність через пози. Це візуальний орієнтир,
не гімнастичний відеоурок. Поточні Instagram trends кількісно не перевірені.
Додаткове джерело техніки:
https://static.usagym.org/PDFs/Women/development/compulsory/2021/replacement_061721.pdf

Нова механіка: підтримуваний ланцюг від нерухомих зап’ясть, прямі руки,
махова нога пряма, друга відштовхується до повного розгинання коліна,
носки витягуються в повітрі. Підготовчий замах, невеликий перехід через
вертикаль і поправка балансу; повернення повільніше, руки опускаються окремо.
Голова трохи більша, з коротким з’єднанням із плечима. Рух8.2s, SVG/JS
без нових залежностей. Актуальні cycle.gif205frames/25fps та overview.gif/png.

Чому змінені математичні тести: попередні перевіряли довжини, але дозволяли
зігнуті опорні руки та механічні стопи. Нові перевіряють пряму опору,
махову ногу, носки, повний loop, 10,001samples для довжин/підлоги/неперервності.
Довжина руки46 замість50 — пропорції нового rig, не послаблення вимог.
Стояча пауза на .98 більше не обов’язкова: нове завершення досягає старту на1.
Для continuity обрано крок .0001 і max .7px: дрібніший крок відрізняє
стрибок від швидкого маху. Виявлене різке розгинання коліна усунено раннім
відштовхуванням, швидкий зворотний замах рук — окремою return track.
