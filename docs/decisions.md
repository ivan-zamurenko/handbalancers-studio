# Решения и приоритет v4

Дата комплекта: 6 октября 2026. Это исполнение утверждённого продукта, не новая продуктовая концепция.

## Подтверждено владельцем
Новый код и baseline БД с нуля; перенос старых аккаунтов/истории не нужен. Старая папка/remote не уничтожаются. Один владелец-тренер, без команды и multi-tenancy. Клиентская часть и админка используют общие сущности/правила.

C1/A1 — общий фундамент; C3 — активная тренировка. Светлая/тёмная, auto по времени пользователя и ручной override. Продукт uk/en; русский — язык этой документации.

Все общие опубликованные программы доступны всем действующим тарифам; private чужих клиентов не доступны. Essential — самостоятельный выбор и конструктор; Plus — целевое ведение AI по видео/фактам; Pro/Pro+ — личный контроль владельца. Один текущий личный план, не более одной текущей основной программы; дополнительные занятия из других источников входят в тот же календарь. Занятый день предлагает заменить, не незаметно добавить. Не копить missed как долг. Основной этап не закрывается чужим допзанятием без разрешённой эквивалентности.

Цены EUR/month: Essential 19.99; Plus 49.99; Pro 179.99; Pro+ 299.99. Trial 7 дней с картой и автоматической месячной оплатой только Essential/Plus, один на аккаунт. Pro+ — два звонка по 30 минут за период и личный чат в согласованных пределах. Plus не включает обязательный еженедельный human review. Неготовые функции не выдавать за доступные.

Тест — программа упражнений по методике владельца, тот же движок C3. Для Essential рекомендация, для Plus+ часть сопровождения. Критерии/пороги и обязательность конкретных тестов не выдумывать.

YouTube приоритет, Vimeo/Drive возможны. Просмотр человеком и AI доступ — разные capabilities. Один текущий контрольный ролик на выполненное упражнение, immutable evidence versions. Можно завершить без видео, техника unreviewed.

Модульный монолит FastAPI/PostgreSQL/Supabase Auth/SQLAlchemy 2/Alembic/Jinja/CSS/vanilla JS. Google и Apple через Supabase; email/password UX сохраняется. «Вход через Supabase» не означает третью социальную кнопку.

TDD, небольшие логичные commits, код корректируется под согласованное поведение. Это поручение разработки, не deployment/live payment/private-data processing authorization.
