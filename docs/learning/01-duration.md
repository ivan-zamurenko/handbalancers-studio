# L01 — перетворити секунди на хвилини й секунди

Мета: написати першу невелику Python-функцію. У Studio схоже форматування
потрібне для тривалості підходу. Зараз працюємо лише з вигаданими числами.

## Що треба знати

Функція приймає значення, виконує обчислення і повертає результат:

```python
def double(number: int) -> int:
    return number * 2

print(double(7))  # 14
```

`number` — параметр; `return` повертає значення тому, хто викликав функцію.
Позначки `int` описують очікуваний тип. Самі по собі вони не перевіряють введення.

Корисні операції на іншому прикладі:

```python
print(17 // 5)  # 3: кількість цілих п’ятірок
print(17 % 5)   # 2: залишок
print(f"{4:02d}")  # "04": щонайменше дві цифри
```

## Ваше завдання

У корені проєкту створіть папку `learning`, а в ній `duration.py`.
Почніть із заготовки й замініть рядок `raise NotImplementedError` своїм кодом:

```python
def format_duration(seconds: int) -> str:
    """Return a non-negative whole duration as minutes:seconds."""
    raise NotImplementedError("Напишіть обчислення тут")
```

У цьому першому завданні вхід — ціле невід’ємне число. Функція повертає
рядок; залишок секунд завжди має дві цифри. Хвилини не обмежені 59.

| Вхід | Очікуваний результат |
|---|---|
| `0` | `"0:00"` |
| `5` | `"0:05"` |
| `59` | `"0:59"` |
| `60` | `"1:00"` |
| `125` | `"2:05"` |
| `3600` | `"60:00"` |

Підказка: одна хвилина містить 60 секунд. Знайдіть окремо кількість
повних хвилин і залишок секунд, а потім об’єднайте їх у рядок.

## Як перевірити

Поруч створіть `learning/test_duration.py` і скопіюйте цей перевірочний код:

```python
import unittest

from duration import format_duration


class DurationTests(unittest.TestCase):
    def test_examples(self):
        cases = {
            0: "0:00",
            5: "0:05",
            59: "0:59",
            60: "1:00",
            125: "2:05",
            3600: "60:00",
        }
        for seconds, expected in cases.items():
            with self.subTest(seconds=seconds):
                self.assertEqual(format_duration(seconds), expected)


if __name__ == "__main__":
    unittest.main()
```

Відкрийте термінал у корені Studio й запустіть:

```sh
.venv/bin/python -m unittest discover -s learning -p 'test_*.py' -v
```

З початковою заготовкою очікується `NotImplementedError` — функцію ще
не написано. Після реалізації очікується `OK`. Якщо тест падає,
подивіться на `seconds` та різницю між вашим і очікуваним результатом.
Перевірки не потребують мережі, БД чи встановлення пакетів.
