# Выбранный дизайн — C1 / A1 / C3

`preview/index.html` — автономный интерактивный макет, скопированный из выбранного пакета v2 без изменения поведения.
`preview/previews/` — 12 PNG: 3 экрана × 2 темы × 2 ширины (390 / 1440).
`preview/reference/selected-overview.jpg` — общий лист выбранного направления.
`preview/assets/` — CSS, JS, семантические токены и самостоятельный theme-controller.
`preview/checks/theme.test.cjs` — проверяемый модуль темы.

## Что считать утверждённым визуальным направлением
C1 — кабинет клиента. A1 — кабинет владельца. C3 — активная тренировка.
Не создавать снова пять вариантов и не подменять минимализм стеклянными панелями, градиентами, декоративными score-карточками.
Основные кнопки монохромные; зелёный — акцент. Используется системный шрифт; font-файлы не приложены.

## Темы
Три режима: auto/light/dark. Авто по времени устройства, не сервера и не обязательной геолокации.
07:00–20:00 — текущая техническая отправная точка, а не явно выбранные владельцем часы.
Ручной выбор сильнее времени. Смена темы не очищает input/textarea.
Предложение: автоматическую смену отложить во время активной тренировки; ручная работает сразу.
В прототипе localStorage и fallback при его недоступности. В приложении добавить user_preferences с ревизией и кешем, разделённым по аккаунтам.
Theme-timezone не заменяет timezone тренировочной недели.
Применяется к обеим ролям; каждый пользователь видит тему по своим настройкам.

## Что ещё предстоит нарисовать и реализовать
Конфликт/preview перепланирования Essential, запрос на изменение, разрешения тренера, полный редактор правил, все страницы библиотеки/программы/оценки и полный набор ошибок.
Эти сценарии определены в спецификациях v3, но не выданы за уже готовые новые изображения.
YouTube на старом выбранном макете — приоритетный пример; надпись не запрещает будущие одобренные Vimeo/Drive.

## Границы макета
Демонстрационные имена, значения, таймеры, графики и подписки — синтетические данные.
Верхняя панель выбора screen/tier — инструмент просмотра, не элемент production.
Макет не подключён к backend, оплате и AI. Не переносить demo entitlement в действующий код.
Фреймы в Figma в этом раунде не создавались. При переносе создавать editable текст/компоненты/иерархию, а не вставлять скриншот как UI.
