# Приоритет и изменения к прежним материалам

| Старое положение | Актуальное положение v3 |
|---|---|
| Не решено, кому открыт общий каталог | Всем действующим тарифам |
| Не решено, одна программа или несколько | Один текущий личный план, одна основная программа; дополнительные занятия |
| Essential выбирает только собственные программы | Общий каталог + собственный конструктор; выбор занятия и согласование календаря |
| Привязка каждого выполнения обязательно к назначению исходной программы | Любое запланированное занятие относится к единому плану; дополнительное может иметь иной источник |
| Видеопровайдер только YouTube | YouTube приоритетен; Vimeo/Drive кандидаты; инфраструктура AI открыта |
| Требуется перенос старых локальных аккаунтов | Перенос не требуется; чистую baseline проектировать локально |
| Предложить пять новых направлений | Выбор завершён: C1/A1/C3 |
| AI/оценка — только общие будущие идеи | Цель Plus уточнена: цикл ведения по видео, фактам, истории и методике; готовность не доказана |
| Один handoff без явно выделенной админки | Отдельная спецификация админки и её сценариев, общий backend и данные |

Исходные архивы оставлены неизменёнными в `90_history/` для происхождения и деталей.
Их вопросы, правовые/технические выводы и тестовые отчёты не становятся автоматически текущими.
В частности, исходный `MODEL_HANDOFF.md` сам содержит исторические разделы; актуальные ответы владельца имеют приоритет.
Пакет v3 не заявляет, что исходный runtime был повторно прочитан или что внешние сервисы проверены в текущем раунде.
