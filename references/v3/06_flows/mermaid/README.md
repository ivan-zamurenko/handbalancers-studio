# Исходники схем
Mermaid-файлы отражают текущую проектную модель v3. Это редактируемый текстовый исходник, не новые Figma/FigJam-объекты и не проверенный SQL.
Названия camelCase в обзорной ER-схеме соответствуют snake_case словаря БД.
ER-схема показывает только ядро и не заменяет все поля/составные ограничения.
Исторические SVG/PNG находятся внутри `90_history/archives/Handbalancers_Studio_blueprint_2026-10-05.zip`; они могут не учитывать единый план v3.
