# Проверяемые вехи, не большие коммиты

| Веха | После задач | Что реально показать |
|---|---|---|
| M0 — среда | S00–S02 | Чистый воспроизводимый запуск, test isolation, light/dark shell |
| M1 — аккаунт | S03–S05 | Local signup/verify/login/profile/onboarding, безопасный paid policy |
| M2 — контент тренера | S06–S07 | Создать упражнение и программу, published immutable tree, private builder |
| M3 — минимальная ценность | S08–S10 | Назначить → выполнить C3 → отчёт → проверить A1, клиент видит feedback |
| M4 — свободный выбор без второго календаря | S11 | Essential replace/add с preview и проверками; coach permissions/requests |
| M5 — оценка | S12 | Тестовая программа проходит через обычный training engine |
| M6 — коммерческий test-mode | S13 + G_STRIPE_TEST | Checkout/trial/webhook/portal в тестовом Stripe, без live продаж |
| M7 — AI-контур | S14 | Fake/shadow evaluated pipeline и защищённый apply, без выдуманной live готовности |
| M8 — сервис и эксплуатация | S15–S16 по gates | Pro+ договорённые каналы, доступность/security, build/restore evidence |
| M9 — согласованный выпуск | S17 | Реальные интеграции, утверждённые тарифы/методика/privacy/infra |

На границе вехи выполнить общий regression и review, но не сливать её 10–20 задач в один большой commit. Для обучения владельца после каждой карточки показывать конкретное изменение; для коммерческой демонстрации — веху целиком. Ни один intermediate checkbox не заменяет реальную проверку внешнего сервиса.

## Поступове AI-ведення — уточнення 2026-11-24

Повний контракт — [AI-супровід](../docs/ai-coaching.md),
навчальні завдання — [learning](../docs/learning/README.md).
Це дрібні checkpoints усередині чинного продукту, не окремі нові продукти.

| Checkpoint | Картки | Перевірюваний результат |
|---|---|---|
| A0 — можливість | S14-00 | Дозволені handstand clips, actual CV/LLM evaluations, права/обмеження/витрати; без fake readiness |
| A1 — запис вправи | Чинні S06–S09, S06-07, S10-10–S10-14 | Приклад → виконання → приватний запис одного підходу; повтор/заміна/видалення, тренування працює без відео |
| A2 — вимірювання | S14-10–S14-14 | Методика, side-view pose, quality і явні метрики; недостатні дані відхиляються |
| A3 — обґрунтований звіт | S14-15–S14-19 | Published knowledge, SQL retrieval, перевірені рекомендації, skeleton overlay; план не змінюється |
| A4 — подальше ведення | S14-20–S14-21 + S14-06/08 | Сумісний прогрес і адаптація майбутніх занять через чинні правила/revisions |
| A5 — допуск | S14-22 + S17-02/03 + owner gates | Shadow → report → proposal → дозволений auto; приватність, quality та kill switch реально перевірені |

Скорочення інфраструктури не скорочує перевірки доступу/даних. Перша
реалізація без pgvector, двох LLM, зовнішньої черги, мікросервісів і
нового frontend. Зміна цих defaults потребує виміряного обґрунтування.
L01 спочатку виконує власник у synthetic sandbox; результати навчання
не є production evidence. Частково реалізований AI не продається як
готовий Plus без виконання погодженого набору можливостей.
