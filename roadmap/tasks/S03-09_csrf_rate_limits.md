## Сначала тесты
| Тест | Что обязан доказать |
|---|---|
| `csrf_missing_rejected` | Authenticated mutation без CSRF даёт 403. |
| `login_csrf_rejected` | Чужой Origin не может привязать браузер к чужому аккаунту. |
| `rate_limit_atomic` | Параллельные попытки не обходят лимит, 429 с безопасным Retry-After. |
| `oauth_callback_exception_narrow` | Исключение для callback не отключает CSRF на остальных routes. |

Команда проверки (создать test-файл до реализации):
```sh
uv run pytest server/tests/security/auth/test_csrf_rate_limits.py -q
```

Ожидаемый RED: как минимум один из новых тестов выявляет именно отсутствующее поведение текущей карточки. Ошибки настройки исправляются отдельно и не выдаются за TDD-доказательство. Для чисто инфраструктурной задачи проверяется её реальная гарантия, а не assert(true).
