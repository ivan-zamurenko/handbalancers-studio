## Сначала тесты
| Тест | Что обязан доказать |
|---|---|
| `duration_integer_ms` | Время хранится целым ms, UI секунды преобразуются явно. |
| `reps_not_duration` | Нельзя отправить reps для duration slot. |
| `zero_not_missing` | Ноль, null и skipped — разные значения. |
| `load_nonnegative` | Отрицательная нагрузка/время не допустимы. |
| `side_consistency` | left/right/both/none разрешены только для соответствующего side_mode. |

Команда проверки (создать test-файл до реализации):
