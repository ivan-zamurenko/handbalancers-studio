## Сначала тесты
| Тест | Что обязан доказать |
|---|---|
| `reload_preserves_pending` | Draft доступен после reload для того же пользователя. |
| `retry_original_id` | Sync повторяет тот же operation/log ID, не создаёт новые. |
| `account_switch_isolation` | После logout/login другим пользователем old drafts недоступны/очищены. |
| `conflict_not_last_write_wins` | 409 требует сравнения, не silent overwrite. |
| `no_offline_paid_start` | Новая session не начинается offline без server entitlement. |

## Особые условия
Это временная offline устойчивость ввода, не полностью автономная PWA. Не обещать офлайн просмотр внешнего видео. IndexedDB failures переводят UI в явный unsaved state.

## Критерий завершения
Все указанные проверки действительно выполнены в заявленной среде; обязательные отказы и repeat/concurrency cases сохранены. Нет skip/xfail вместо требуемой гарантии. Новый API подключён в app только после соответствующих guards. Нет фиктивных данных в production-экране. Есть проверяемый результат и узкий diff.

Если зависимость/ключи недоступны, сохранить blocker и перейти только к следующей реально доступной независимой задаче. Нельзя объявить внешнюю функцию готовой по mock. Возникший дефект чужого модуля получает отдельную карточку, не скрытый rewrite.
