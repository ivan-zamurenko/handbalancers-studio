## Сначала тесты
| Тест | Что обязан доказать |
|---|---|
| `client_read_denied` | Ни GET client report, ни session detail не содержит body заметки. |
| `client_export_denied` | Экспорт/уведомление клиента не сериализуют notes. |
| `coach_access_required` | Даже coach без active relationship не пишет заметку. |
| `no_default_ai_forward` | Note не отправляется AI без соответствующего processing purpose. |
